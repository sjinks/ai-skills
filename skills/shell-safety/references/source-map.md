## Provenance Notes

- `Source domain` values are provenance groupings only. The `category` emitted in `Matched patterns:` always uses one of the four Category Index labels defined in the core skill.
- The skill is intentionally command-centric: it reviews one command, script fragment, or proposed terminal action before execution.
- The pattern IDs are local stable labels for reporting and eval assertions; they are not external standards identifiers.
- Confirmation gates independently bind the command source actor that originated/confirms the action and the credential-backed authenticated execution principal/account, rather than inferring either from credentials, authorities, destinations, targets, working-directory ownership, repository account, or author/signing identity. They also bind the normalized command, working directory, interpreter, resolved safety-relevant non-secret expansions, platform/repository context, target identifiers, reviewed preview or plan digest, and relevant branch tips or object versions. Refresh mutable evidence and both actor identities immediately before execution; any changed or unverifiable binding requires reclassification.

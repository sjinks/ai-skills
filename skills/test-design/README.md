# test-design

> Design and implement a small, risk-focused set of automated tests for a feature or module, or assess suite-level gaps.

This framework-independent skill derives cases from observable behavior, requires each case to catch a plausible defect, follows repository test conventions, and reports verification honestly. It distinguishes feature-level design from a standalone review of one test or diagnosis of an intermittent failure.

## Files

- [`SKILL.md`](SKILL.md) — workflow, decisions, output, and completion checklist.
- [`references/test-selection.md`](references/test-selection.md) — detailed guidance for choosing cases and assertions.

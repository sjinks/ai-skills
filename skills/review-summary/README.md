# review-summary

> Write a friendly, evidence-backed message for the overall pull request review.

Use this skill for approvals, requests for changes, and general review feedback. Acknowledge a specific contribution when the review notes support it. Explain the reviewer’s decision and point the author to the next step. Keep routine CI results out of the message.

## Files

- [`SKILL.md`](SKILL.md) — workflow, output, and missing-input handling.
- [`references/examples.md`](references/examples.md) — messages for requesting changes and approving a fix.

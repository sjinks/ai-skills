# review-summary

> Write a friendly, evidence-backed message for the overall pull request review.

Use this skill for approvals, requests for changes, and general review feedback. Look for a specific improvement in the review notes or available PR context. When the evidence supports one, name it in the first sentence, even when requesting changes. Explain the reviewer’s decision and point the author to the next step. Keep routine CI results out of the message.

# commit-hygiene

> Plan or audit an unmerged branch's commit sequence without running Git.

Recommends fixup squashing, evidence-backed dropping, splitting mixed commits, dependency ordering, and reword targets. It returns a rebase todo, per-commit actions, a resulting sequence, cautions, and author questions with a `CLEAN`, `CONCERNS`, or `BLOCK` verdict. Individual message writing, PR splitting, and code correctness review are outside its scope. Apply it to history-planning subtasks within PR preparation or maintenance when cleanup decisions are needed; ordinary commit creation alone does not activate it. The caller supplies Git evidence and retains execution and authorization.

Unknown merge style uses preserved-commit rules; squash merge focuses on final content. Uncertain changes stay pending rather than being discarded. Rewrite plans require backup and publication cautions. Emit a concrete backup command only when supplied evidence identifies a valid unused branch name and hexadecimal original-tip hash; quote both arguments; otherwise describe the requirement and request missing values. Moves and nonadjacent folds require evidence for crossing intervening commits without breaking dependencies or review boundaries; unresolved moves/folds stay at their original positions. Both fixup and squash attribute the result to the first commit's author. Required distinct authorship metadata that would be lost, or unknown preservation, keeps the commit as needs-author-input / unchanged pick. An explicitly author-approved message-based attribution alternative permits squash with pending message review; message review does not preserve Git authorship metadata. For folds preserving required authorship metadata directly, use fixup only when no required unique message information is lost; otherwise use squash with pending message review. Every fold also requires the movement gate to pass. Missing or invalid range metadata or merge topology uses the reduced `BLOCK` report; an explicitly empty range is valid. Missing change summaries or verification stays pending in the full report. Audit reports retain required safety recommendations without directing execution of the cleanup plan. Actions explicitly include severity. Todo and Actions contain each input commit once; Resulting sequence removes drops/folds and expands splits. Net content is preserved except explicitly author-approved discards.

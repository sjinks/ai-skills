# review-comment

> Turn each evidence-backed finding into its own pull request review comment.

Use this skill to draft or rewrite comments for a PR author. Each comment has a short bold heading and inline labels for impact, estimated priority, fix direction, and verification. Add reproduction steps when they help the author see the failure. Include a short code sample or pseudocode when it makes a fix or check easier to understand, and leave routine CI results in CI.

The writing rules borrow short sentences, consistent terminology, and direct instructions from [ASD-STE100](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf).

- [`SKILL.md`](SKILL.md) — authoring rules, priority rubric, and comment format.
